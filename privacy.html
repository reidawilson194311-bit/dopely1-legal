Privacy Policy

Last updated September 9, 2026

Who this covers

Dopely1 Uploader is a single-user personal automation tool. The only TikTok account it ever connects to is the Operator's own account. It does not collect, process, or store data belonging to any other individual.

What data is accessed

ScopeUsed for
user.info.basicConfirming which account is connected
video.publishPublishing video content directly to the connected account
video.uploadUploading video content as a draft when direct publishing isn't used

How it's used

Data obtained through TikTok's API is used exclusively to operate the posting functionality described above. It is not sold, shared, or disclosed to any third party, and is not used for advertising or analytics purposes.

Storage

Authentication tokens are stored locally on the Operator's own device and are not transmitted anywhere other than to TikTok's API to authenticate requests.

Data deletion

The Operator can revoke this application's access at any time from TikTok's account settings, which immediately invalidates any stored authentication token.
